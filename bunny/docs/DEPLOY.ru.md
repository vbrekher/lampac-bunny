# Lampac Bunny — установка на Bunny

## Быстрый старт

Нужны macOS или Linux, Bash, curl, **Python 3.10+** и аккаунт Bunny с доступом к Magic Containers. Настраивать Docker, GitHub, VPS или SSH не требуется.

```bash
curl -fsSL https://raw.githubusercontent.com/vbrekher/lampac-bunny/main/bunny/scripts/install-bunny.sh | bash
```

Получите **ключ API аккаунта** в [панели Bunny](https://dash.bunny.net/), в разделе аккаунта и API. Введите его в скрытом запросе терминала. Установщик передаёт ключ только Bunny, не сохраняет его и запрещает перенаправления запросов с ключом. Для автоматизации поддерживаются переменные `BUNNY_API_KEY` и `BUNNYNET_API_KEY`; не записывайте секреты в историю команд.

**Живая приёмка: PASS.** Проверено **2026-11-04 UTC** на настоящей инфраструктуре Bunny в **AMS**, с закреплённым образом **v0.1.3**. Пройдены проверки HTTPS, JavaScript и плагина, сохранности SQLite, восстановления после перезапуска и сбоя, повторной установки и закрытых административных маршрутов. См. [отчёт](../../docs/acceptance/LIVE_BUNNY_ACCEPTANCE.md) и [доказательства JSON](../../docs/acceptance/live-bunny-results.json). Физические телевизоры и все провайдеры по отдельности не проверялись.

Анонимный доступ к публичному GHCR проверен. Установщик выбирает публичный реестр GitHub и не требует ключей GitHub.

## Автоматическая настройка

Установщик проверяет `ghcr.io/vbrekher/lampac-bunny:v0.1.3`, ожидаемый digest `sha256:25353ce71cf3bd5298877fd3b1cd40b2e9cbbeeaa8713fbedc126a02c69e66f2` и `linux/amd64`. Он закрепляет digest в конфигурации Bunny, выбирает один доступный европейский регион, начиная с AMS, подключает GHCR и создаёт:

- Одно приложение `lampac-bunny` с общим типом среды и минимальным/максимальным числом реплик, равным единице.
- Один постоянный том 5 ГБ, подключённый к `/lampac/database`.
- Внутренний HTTP-порт `9118` и публичный адрес CDN с HTTPS.
- Случайный `LAMPAC_ROOT_PASSWORD` и проверки запуска, готовности и жизнеспособности на `/version`.

Вычисления, хранение и трафик CDN оплачиваются по тарифам Bunny. Установщик ждёт до 600 секунд непустых ответов HTTP 200 от `/version?type=hash` и `/online.js`. Это базовая проверка доступности, а не полная приёмка.

## Адрес сервера и подключение

Адрес появляется в терминале и на вкладке адресов приложения `lampac-bunny` в Magic Containers. Добавьте `https://YOUR-ENDPOINT/online.js` в настройках плагинов совместимого клиента Lampa. Каталоги и воспроизведение проверяйте отдельно на разрешённом контенте: успешный ответ API не подтверждает воспроизведение видео.

Пароль и сведения о развёртывании сохраняются в `~/.config/lampac-bunny/deployment.json` либо в каталоге `XDG_CONFIG_HOME`, с правами `0600`. Сделайте защищённую резервную копию. Не публикуйте этот файл и ключи.

## Повторный запуск и обновление

Повторите исходную команду: установщик найдёт подходящее приложение и сохранит его тома. Незавершённое или неактивное развёртывание запускается повторно. Несовместимый образ, несколько приложений с одним именем или несогласованное локальное состояние приводят к остановке для проверки.

```bash
# Повторное развёртывание того же образа, ожидание HTTPS до 15 минут.
curl -fsSL https://raw.githubusercontent.com/vbrekher/lampac-bunny/main/bunny/scripts/install-bunny.sh | bash -s -- --redeploy --timeout 900
# Регион нового приложения, если в нём доступны ресурсы.
curl -fsSL https://raw.githubusercontent.com/vbrekher/lampac-bunny/main/bunny/scripts/install-bunny.sh | bash -s -- --region DE
```

Локальная блокировка предотвращает одновременные установки на одном компьютере. Не запускайте создание ресурсов одновременно с разных компьютеров. После таймаута создания проверьте панель Bunny перед повтором. Не удаляйте существующие приложения и тома ради восстановления. Известные развёртывания v0.1.1/v0.1.2 обновляются до проверенного закреплённого выпуска v0.1.3 с сохранением тома, пароля, CDN и пользовательской конфигурации. Другие образы отклоняются. Опубликованные теги не перезаписываются.

## Типовые ошибки

| Ошибка | Действие |
| --- | --- |
| Bunny 401/403 | Проверьте ключ API аккаунта и доступ к Magic Containers |
| GHCR недоступен или digest отличается | Проверьте публичность пакета; не отключайте проверку digest |
| Нет ресурсов в регионе | Повторите позже или выберите доступный европейский регион |
| Таймаут запуска или HTTPS | Проверьте контейнер, проверки здоровья, адрес CDN и журналы; увеличьте время ожидания |
| Установка прервана | Повторите команду: приложение и том будут переиспользованы |
| Локальное состояние не совпадает | Сопоставьте защищённый локальный файл и приложение в Bunny перед изменениями |
| Диск Docker доступен только для чтения | Запустите `bash bunny/scripts/doctor.sh`; восстановите хранилище Docker, сохранив тома |

## Локальная разработка и конфигурация

```bash
bash bunny/scripts/preflight.sh
python3 bunny/scripts/test_deploy_bunny.py
bash bunny/scripts/test-local-acceptance.sh
# Используйте собственный новый тег версии:
bash bunny/scripts/build-image.sh YOUR-REGISTRY/lampac-bunny:NEW-VERSION --load
```

Параметр `--push` публикует образ после авторизации в реестре. Облегчённая сборка из исходников использует .NET 10 и не содержит Chromium, FFmpeg и GStreamer. Для них нужен отдельно проверенный образ. Необязательные модули Sync, TimeCode, TorrServer, JacRed, WebLog и SISI изначально отключены.

Переменная `LAMPAC_BUNNY_CONFIG_B64` позволяет передать собственный `bunny/config/init.conf`. Base64 не шифрует данные. Рабочая конфигурация имеет приоритет над `config/base.conf` и значениями из кода; сохраните внутренний HTTP на `0.0.0.0:9118`, а для внешних адресов укажите `listen.scheme="https"`. Для локальной разработки без TLS можно указывать `http`. Начальный скрипт проверяет JSON и параметры порта, но не безопасность каждого модуля.

## Безопасность и данные

Корневой пароль защищает административные функции, но начальная конфигурация не обеспечивает универсальную авторизацию всех API. Публичному CDN нужны проверенные ограничения маршрутов, авторизация и лимиты запросов. Живые запросы к универсальным ретрансляторам без авторизации получили 401/400/404; разрешённый синтетический поток успешно декодирован. Храните токены ретрансляции в секрете.

SQLite требует одной реплики в одном регионе. `/lampac/database` содержит локальную SQLite, а не Bunny Database. Делайте согласованные резервные копии и проверяйте восстановление. Не удаляйте пользовательские данные ради тестов. Перезапуск, SQLite и журналы .NET проверены в связанном отчёте живой приёмки. Разрушительные тесты выполняйте только на отдельном тестовом экземпляре.
